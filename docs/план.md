## Как работаем дальше

- Разработка через тесты: `scripts/test.sh` (без сети, окружение вне папки проекта), правила кода — глобальные
  правила владельца. Бот запускается только на сервере.
- Меняется утверждённое в ТЗ — сначала владельцу, потом `docs/ТЗ.md` (версия, статус, раздел 20), потом код.
- Выкладка и откат — владелец: `deploy/deploy.sh [sha]`, порядок и памятка — `docs/эксплуатация.md`.
- После этапа — запись в `JOURNAL.md` (вне git); новый крупный этап — новый раздел ТЗ и новый план в этом файле.
