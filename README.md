# @jw_site_check_bot

Проверка сайта в Telegram: присылаешь ссылку — получаешь отчёт словами о скорости на телефоне, мобильной версии,
защите и картинках. Бот экосистемы `>jw_` — jw-dev.pro.

## Как устроено

```
ссылка → разбор и защита сети → очередь (2 воркера)
       → до замера: DNS, TLS → PageSpeed Insights (Lighthouse на серверах Google) → после замера: сертификат, http → https
       → оценки по правилам → rich-сообщение: «Проверяю…» превращается в отчёт
```

- Python 3.12, aiogram 3.31 (Bot API 10.3), SQLite, Docker.
- Свой сервер бот не нагружает: страницу меряет Google.
- Защита домашней сети — в коде (только глобальные IPv4, соединение с проверенным адресом) и своей таблицей
  nftables для контейнера. Перезапустили nftables (`sudo systemctl restart nftables`) — это останавливает
  и Docker (так и задумано, без таблицы контейнер не работает): `sudo systemctl start docker`, затем
  `deploy/check_isolation.sh`.

## Разработка

```bash
git config core.hooksPath .githooks   # один раз в свежей копии: хук не пустит секрет в коммит
scripts/test.sh                       # тесты без сети; окружение — вне синхронизируемой папки
```

- Бот запускается только на сервере; на Маке — только тесты.
- Секреты — только в `.env` на сервере. Адреса и пути сервера в репозиторий не пишутся.
- Выкладка: `deploy/deploy.sh` (подробно — в памятке).
